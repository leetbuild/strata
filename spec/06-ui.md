# 06 — The shell (C++ Qt 6 Widgets)

## Why Widgets in C++
qss stylesheets only apply to Qt Widgets, and Rust has no good Widgets bindings. So the window is a thin C++
program that owns no state: every model, action and setting lives in the Rust core and crosses the `cxx` bridge
(`docs/ARCHITECTURE.md`). The shell is views, delegates, dialogs and the glue.

## Look: MO2 2.5.2, as close as possible
- Start from MO2's own Designer forms (`MO2/modorganizer/src/*.ui`: `mainwindow.ui`, `modinfodialog*.ui`,
  `settingsdialog*.ui`, `profilesdialog.ui`, `editexecutablesdialog.ui`, ...). GPL-3: Strata is GPL-3.
- Main window: big icon toolbar (Leet's slim set), left pane = profile row (Profile combo, `...` menu, folder
  menu, backup buttons, active counter) above the mod list, filter row below it; right pane = executable combo +
  Run + shortcut above the tabs Plugins / Archives / Data / Saves / Downloads (+ Leet's Root tab); categories
  filter panel on the far left; log dock at the bottom; status bar.
- Delegates as MO2's: flag icons, content icons, conflict highlight colours, separator rows with colours and
  Sub-Separator `#` levels and `(n)` counts.

## Style
- Load `.qss` from `<instance>/stylesheets/` and `~/.local/share/strata/stylesheets/`; MO2's own sheets
  (`vs15 Dark`, `Paper Light`, ...) are bundled. Follow symlinks (Fluorine rejected them, which broke the rice).
- **Hot reload**: watch the active sheet (and handle replace-by-rename); on change re-apply the app sheet and
  repolish. No widget-level sheets that would override it (Fluorine's `FluorineTheme` did, which froze the
  lists' colours).
- Desktop themes may render sheets (`riki.qss`) into the stylesheets folders and switch them live
  (`qs -c riki ipc call theme set gruvbox-dark`): the mod list must follow within a second.
- Fonts: the system's (no bundled DejaVu override unless missing).

## Behaviour
- The UI thread never blocks on disk: scans, installs, downloads, VFS refresh run in the core's workers and
  report progress events.
- Header state, splitters, window geometry saved on change (Leet), restored per instance.
- Every action reachable from the menu bar too (keyboard users), as in MO2.

## Build
CMake + Qt 6 (Arch `qt6-base`, system Qt), Corrosion to build the Rust crates into the same binary. One command:
`tools/build.sh` (Rust + C++), output `build/strata`.
