# Changelog

## 0.1.0 (unreleased)
First public version.
- MO2 2.5.2's main window and dialogs (mod list with nested separators, plugins with LOOT sorting, Data,
  Archives, Saves, Downloads and Root tabs, mod information, profiles, executables, settings), MO2's
  stylesheets with live reload.
- MO2-compatible instances, read and written byte for byte; the instance manager and a new-instance wizard.
- The FUSE overlay with Overwrite and Root folders; launching through Proton and the Steam Linux Runtime;
  prefix setup from scratch.
- Installers (FOMOD, BAIN, quick, manual, Root sorter), Nexus login, `nxm://` links, downloads, update checks.
- Built in: BSA/BA2 tools, ini editor, previews, Problems checks, crash log viewer and labeler, install
  under a separator, CSV export, Overwrite sync.
- The `strata` command line with `--json` output.
- Games: Skyrim SE, Skyrim LE; Oblivion experimental.
